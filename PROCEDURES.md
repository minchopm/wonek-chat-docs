# Wonek — operating procedures

Use these procedures as task-oriented reference. They describe public capabilities and verification steps, not private implementation. UI labels can vary by version.

## Procedure 1: Check a first call and file transfer

### Before you begin

Use compatible early-access builds and a consenting contact.

### Steps

1. Confirm the intended Personal or Work context.

2. Exchange a short non-sensitive message and verify the recipient.

3. Start a brief call and test microphone, output route and camera as needed.

4. Send a small sample file and ask the recipient to open it.

5. Repeat only the failed part after a connectivity change.

### Expected result

The intended contact receives the message/file and both people can hear the call.

### If the result differs

Pre-release features may differ by build. A relay path is not evidence of disabled encryption; a direct path is not guaranteed.

## Procedure 2: Prepare screen sharing

### Before you begin

Close private windows and choose a sample task.

### Steps

1. Check the current conversation and participants.

2. Prepare only the window or screen material needed for the task.

3. Start the available screen-sharing flow and ask the recipient what is visible.

4. Complete the demonstration without opening unrelated content.

5. Stop sharing and confirm the stream has ended.

### Expected result

Only the intended demonstration is visible to the intended participants.

### If the result differs

If the recipient sees the wrong content, stop and reselect. Encryption does not prevent accidental disclosure to a participant.

## Report a repeatable problem

Record app/version, device/OS, selected mode, input conditions and the smallest failing step. Distinguish expected behavior from the observed result. Use synthetic examples and omit credentials or private records.
