# Wonek — practical workflows

These are suggested user procedures, not claims that automated tests have been performed. Each workflow has a concrete outcome to inspect.

## A family call

Confirm participants are using compatible builds. Test microphone and speaker routing before beginning. If the connection is poor, reduce competing network use or try another connection. A call using a relay is not proof that encryption is disabled.

## Share a file and verify receipt

Use a sample file first, note its size and ask the recipient to open the received copy. If interrupted, follow the app's transfer state rather than assuming completion. Retain the original until the recipient has verified the file.

## Keep work and personal contexts separate

Check the active profile before sending media, starting screen sharing or editing a shared document. Close unrelated windows before a demonstration. An encrypted transport cannot prevent a recipient from seeing content you intentionally share.
