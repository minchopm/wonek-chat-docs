# Wonek — frequently asked questions

## What should I check when using messages and calls?

Pre-release capabilities can change; verify availability in the supplied build.

## What should I check when using files and workspace?

Transfers and synchronization depend on participant connectivity and the available app version.

## What should I check when using connection behavior?

A direct path is not guaranteed on every network; this guide does not publish internal routing algorithms or security-audit claims.

## Where should I start?

Use the quick-start guide with a small example, verify the saved result, then choose a practical workflow. Avoid beginning with irreplaceable data or an entire production project.

## How do I report a documentation or app problem?

Use the official product support channel for account or purchase issues. A public GitHub issue is suitable for documentation corrections and sanitized reproduction steps. Include the app version, device/OS, expected outcome and actual result; do not attach private data.
